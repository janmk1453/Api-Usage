文档说明

API用量统计使用文档

本页是 SillyTavern 扩展“API用量统计”的功能参考与使用文档，覆盖各页面能查看的数据、常用操作、字段口径、隐私边界和常见问题。

文档定位

文档以当前扩展界面为准，重点回答三个问题：页面上有什么、这些数据代表什么、遇到问题时应该检查哪里。操作步骤只保留在完成配置所必需的位置，不展开实现原理。

适合谁看首次安装用户、需要核对费用与 Token 的用户，以及维护多钱包和云同步的用户。
需要什么条件SillyTavern 已安装并启用扩展，且实际发起过至少一次可被记录的模型请求。
数据从哪里来扩展记录实际请求产生的 Token、费用、时间、模型和连接信息，并以页面汇总展示。
版本说明本文不写死版本号，请以扩展侧边栏、关于页或扩展清单显示为准。

阅读方式

  • 左侧目录用于在主要章节之间跳转，右侧“当前章节”用于在同一章节内定位。
  • 顶部搜索支持按页面名称、功能名称和关键词筛选；按 / 可快速聚焦搜索框。
  • 标题右侧的井号按钮用于复制当前章节的直达链接。
  • 底部或右上角提供上一章、下一章和回到顶部入口。

主题、目录与跳转

顶部主题切换提供“浅色”和“深色”两个明确选项，点击后立即生效，并记住本次选择。首次打开时如果没有历史选择，会先参考操作系统的颜色偏好。

移动端说明：顶部菜单按钮打开完整目录；选择章节、点击遮罩或按 Esc 均会关闭目录。

页面中的通用交互

控件含义使用方式
胶囊下拉用于选择时间、模型、对话、接入、密钥、钱包或显示模式。点击展开，选择后自动刷新当前页数据；部分下拉支持多选。
复选框用于多选筛选或开关设置。选中或取消后立即应用，部分多选下拉会保持展开以便连续选择。
数字输入框用于金额、间隔、汇率或调试样本数量。输入后按页面提示保存或触发重算。
日期输入框用于自定义统计范围和价格生效日期。范围页开始日期晚于结束日期时，扩展会自动交换。
卡片操作按钮用于查询、导入、导出、同步、展开、忽略或重置。按钮以页面实际状态启用或禁用，操作结果会通过提示文字反馈。
快速开始

快速开始

完成安装后，最少只需要进行一次真实对话，就能在概览和历史记录中看到数据。余额、模型价格和多钱包属于可选配置。

  1. 按照安装方法安装并启用“API用量统计”扩展，刷新网页。
  2. 打开右下角魔法棒菜单，点击“API用量统计”进入主面板。
  3. 在酒馆中发起一次对话。扩展会在请求过程中记录用量，在生成结束后写入历史。
  4. 进入“用量概览”或“历史记录”，确认已经出现模型、Token、费用或耗时记录。

配置余额与费用

  • 需要查看余额或剩余轮数预测时，进入“钱包”设置手工余额，或为 DeepSeek 官方直连钱包填写校准密钥。
  • 需要准确计算非内置模型费用时，在对应钱包中添加模型价格，或配置价格来源后同步价格。
  • 概览页的余额口径只影响余额和剩余轮数预测，不改变其他统计快照的范围。

从筛选开始查看

“用量统计”支持时间、模型、对话、接入类型和 API 密钥五个维度。第一次使用建议先保持“全部”，确认总数据存在后，再逐步增加筛选条件。模型支持多选，适合对比多个模型或渠道。

第一次看不到数据时

  • 确认请求确实由 SillyTavern 发出，并且不是取消的请求或密钥错误导致的空请求。
  • 确认当前聊天范围没有把旧记录过滤掉；“全部历史”会显示所有已记录对话。
  • 进入历史记录检查是否存在条目；如果历史有条目而统计为空，通常是统计页筛选条件过窄。
  • 没有模型价格时费用可以为零，但 Token 和请求次数仍应正常记录。
安装与更新

安装与更新

标准安装流程与扩展管理流程完全一致，更新后需要刷新网页，使新的入口脚本和样式生效。

安装

  1. 点击“安装扩展程序”，输入 https://github.com/janmk1453/Api-Usage。
  2. 刷新网页，在右下角魔法棒中确认出现“API用量统计”入口。
  3. 扩展支持导入旧版数据，已存在的历史可以在“导入、导出”入口中恢复。

更新

在管理扩展程序中点击更新，完成后刷新网页。关于页也提供检查更新功能，用于查看当前状态和可用更新。

旧数据兼容

旧版导出数据可以通过导入功能进入当前版本。导入后，扩展会按记录时间、模型、Token、钱包、接入和密钥信息进行去重；钱包配置也会随兼容格式一并恢复。

更新前建议：重要历史和多钱包配置可以先导出备份。更新不会自动删除浏览器中的历史数据。
界面与导航

界面与导航

扩展以全屏面板打开，导航分为用量、分析和配置三类页面。桌面端使用可折叠侧边栏，窄屏使用抽屉目录。

入口与面板

  • 点击 SillyTavern 右下角魔法棒中的“API用量统计”打开面板。
  • 点击右上角关闭按钮退出面板；点击遮罩区域也可能关闭面板，具体取决于当前面板状态。
  • 主题设置会影响整个扩展；颜色模式可以在“设置”中调整。

桌面端与移动端

桌面端侧边栏常驻显示，可切换展开和折叠。主内容区域保持固定最大宽度，表格和图表在内容区内滚动。
移动端顶部显示汉堡按钮和当前页面名称，点击汉堡打开导航。选择页面后抽屉会自动收起。

通用规则

  • 所有选择类控件使用胶囊下拉，选择后会立即刷新当前页面的数据和图表。
  • 多个筛选条件按交集生效，不是分别相加。
  • 统计页和趋势预测页的部分选择只影响当前页，不会修改历史原始数据。
  • 隐藏页面中的图表会延迟初始化，切换到对应页面后再渲染。
用量概览

用量概览

概览页用于快速判断当前还有多少余额、总共花了多少，以及最近主要消耗在哪些日期、模型和对话上。

充值余额与余额口径

“充值余额”卡显示当前选择的钱包余额。右上角“余额口径”可以切换 DeepSeek 官方钱包、全部钱包合计或其他钱包。

  • 余额口径只影响余额显示和剩余轮数预测，不改变概览、统计和历史中的其他全量指标。
  • 手工余额直接使用填写值；自动校准仅支持支持该能力的官方直连钱包。
  • 多个钱包不会自动把某个密钥余额相加，只有选择“全部钱包合计”时才汇总各钱包已设置余额。

累计消费与总 Token

“累计消费”显示已记录请求的总费用，并按当前显示币种换算；“总 Token”显示输入、输出和缓存相关 Token 的合计。

费用为零不一定代表没有用量：如果模型没有价格规则，Token 和请求次数仍会记录，但费用列可能显示为零或待定价。

历史消耗与支出明细

两组明细用于拆解总量：

区域包含指标说明
历史消耗Token 历史、命中、未命中、输出描述请求使用的 Token 结构，帮助判断上下文和缓存效果。
支出明细预计节省、输入支出、输出支出展示费用主要来自输入还是输出，并估算缓存命中带来的节省。

八块指标卡

指标卡展示每轮费用、每轮 Token、平均耗时、输出速率等常用指标。每块卡右上角可以切换该卡显示的具体指标，方便按自己的习惯组合概览。

每轮费用平均每次调用产生的费用。
每轮 Token平均每次调用使用的 Token。
平均耗时请求从开始到结束的平均时间。
输出速率生成阶段每秒输出的 Token 数。
思维链占比思维链 Token 在输出中的比例。
截断率以非常规数据结束的请求比例。

Token 热力图

热力图按日期汇总近两年的 Token 使用量，颜色越深表示当日使用量越高。悬停或点击主要日期格可以查看日期和 Token 数值；窄屏下可在卡片内部横向滑动。

按对话统计

按对话汇总轮次、缓存命中、未命中、输出、总 Token、总费用、平均 Token 和平均命中率，并按总 Token 从高到低排列。

  • 对话名称优先使用聊天名称；没有名称时使用聊天标识或“未分组/旧数据”。
  • 该表使用完整热冷历史，不受统计页当前筛选条件影响。
  • 全量历史需要读取冷库时会异步补充，首次打开可能短暂显示热历史范围。
用量统计

用量统计

统计页用于按时间、模型、对话、接入和密钥分析费用、Token、请求表现和趋势。所有筛选条件会共同作用于本页汇总、表格和图表。

五维筛选

筛选可选内容使用说明
时间维度全部、今天、昨天、近 7 天、近 30 天、本月、上月、自定义日期自定义范围支持直接输入开始和结束日期；全部范围从已有记录的起始时间开始。
模型全部模型或一个、多个模型支持复选多选；未选择时表示“全部”，单选显示模型名，多选显示已选数量。
对话全部、当前对话、指定聊天或未分组用于把统计限定到某个聊天上下文。
接入类型全部、已识别接入、未记录接入按接入地址区分官方接口、代理和其他连接。
API 密钥全部、已识别密钥、未识别密钥密钥选项会随接入类型联动；切换接入后密钥筛选重置为全部。
模型多选：在模型下拉中勾选多个项目可以同时比较。点击“全部模型”会清空选择，恢复全量统计。

汇总与指标卡

页面上方三块显示消费金额、API 请求次数和总 Token；下方四块显示可配置指标，例如每轮费用、每轮 Token、思维链占比和截断率。

  • 费用会自动按当前显示币种换算。
  • 指标卡使用同一筛选结果，改变任何筛选条件都会同步刷新。
  • 窄屏下汇总卡和四小块会使用两列或单列布局，内容不会横向溢出屏幕。

模型汇总表

模型汇总表按模型展示调用次数、缓存命中、缓存未命中、输出、总 Token、总成本、平均成本、平均耗时和平均速率。除模型列外的表头可以点击排序，再次点击可切换升降序。

自定义图表

“自定义图表”允许分别选择纵轴和横轴：

  • 纵轴支持多项指标，可以同时显示 Token、费用、请求量或性能数据。
  • 横轴支持轮次、每小时、每日、每周、每月等时间粒度。
  • 费用类轴会按当前币种换算，悬浮提示显示对应单位和值。

扩展图表与模型趋势

图表主要观察内容
Token 趋势Token 结构、使用量变化和堆叠走势。
费用趋势费用随时间的变化及输入、输出成本构成。
缓存命中趋势缓存命中率变化和面积走势。
请求数趋势调用频率和请求数量变化。

模型调用次数趋势不同模型的调用频率变化。

筛选或无数据状态

  • 统计为空时先检查时间范围、模型多选、对话、接入和密钥是否组合过窄。
  • 图表显示“该筛选无数据”表示历史中存在记录，但当前条件没有交集。
  • 如果历史页也没有记录，应先确认请求已经完成并产生了 API 用量数据。
历史记录

历史记录

历史页按时间倒序展示每一次已记录的调用，用于核对单次请求的费用、Token、性能、缓存和原始返回信息。

历史范围

“全部历史”显示所有对话记录；“当前对话”只显示与当前聊天文件关联的记录。旧记录没有关联对话时，只在全部历史中可见。

四维筛选与分页

  • 支持模型、对话、接入类型和 API 密钥筛选，条件按交集生效。
  • 接入类型与密钥联动；切换接入后，密钥筛选会回到全部。
  • 筛选先作用于热历史和冷库全量历史，再进行分页，每页显示一定数量的记录。
  • 没有结果时可以点击清除筛选恢复，不必逐项重置。

单条记录

每条记录包含模型和时间、输入与输出 Token、耗时、速率、费用，以及缓存命中、未命中和输出的三色占比条。点击“详情”会向下展开对应内容。

详情内容

基础信息模型、时段、钱包、计价来源、日期和时间。
性能耗时、首字延迟、速率、思维链耗时、思维链占比和是否截断。
Token 消耗缓存命中、缓存未命中、输出、总 Token 和思维链 Token。
费用明细输入费用、输出费用和总费用。

详情底部提供四个数据页签：请求参数、完整响应、原始 Token 用量和消息内容。长文本会在固定高度区域内滚动，避免破坏列表布局。

隐私字段说明：历史详情可能显示请求和响应信息，但这些信息只按扩展的数据清理规则保存。不要在公开环境中直接分享包含个人内容的详情。

新旧缓存断点对比

在两条记录上分别点击“旧”和“新”，页面会并排显示两条内容并高亮差异。缓存断点对比适合观察同一对话在不同时间点的上下文、缓存命中或请求参数变化。

  • 先选择较早的记录为“旧”，再选择较晚的记录为“新”。
  • 差异高亮用于辅助定位变化，不会修改原始历史数据。
  • 记录数量较多时，先使用筛选和分页缩小范围，再进行对比。
趋势预测

趋势预测

预测页根据历史轮次估算后续 Token、费用、可继续轮数和上下文压力。结果用于辅助判断趋势，不是精确承诺。

选择对话

  • “当前对话”优先跟随正在使用的聊天，适合直接查看当前上下文的压力。
  • “全部”会把所有记录合并估算，适合查看整体平均趋势。
  • 选择具体对话时，只使用该对话的历史轮次。
  • 未分组或旧数据没有聊天标识，可在对应选项下查看。

预测卡

预测卡展示预计还可继续的轮数、余额口径与上下文口径、下一轮成本、下一轮输入 Token 和近期命中率。

指标含义
预计轮数按当前余额和用量趋势估算还能支持多少轮；存在区间范围。
余额口径受概览页选择的钱包余额影响。
上下文口径按模型上下文上限估算，可能早于余额达到限制。
下一轮成本根据当前趋势估算的下一次调用费用。
下一轮输入 Token预计下一轮请求规模，可用于判断是否需要压缩上下文。

预测趋势图

图表显示历史输入 Token 散点、拟合线、未来若干轮的预测延伸、置信区间和上下文上限参考线。虚线表示拟合或预测，不等于真实请求结果。

敏感度分析

敏感度滑块用于假设不同的缓存命中率。拖动后，页面会重新估算剩余轮数和命中率下降对轮数的影响，适合评估提高缓存命中或压缩上下文的收益。

能耗等级与最耗对话

  • 能耗等级从 A 到 G 展示，综合增量、输出、效率、命中、截断和思维链占比。
  • 等级越低通常表示上下文增长更快、输出或思维链比例更高，继续对话的成本压力更大。
  • “最耗对话 Top”保持全局对比，用于定位长期消耗较高的聊天。

使用前注意

  • 样本过少时无法可靠预测，页面会提示至少需要若干轮历史。
  • 没有设置余额时，只能查看部分趋势，不能得到可靠的余额剩余轮数。
  • 模型价格、缓存命中率和上下文长度发生变化时，预测结果会随历史数据重新调整。
钱包

钱包

钱包页按接入地址组织余额、密钥、模型和价格。它解决的是“同一接入下的请求花在哪里、余额还有多少、模型费用怎么计算”这几个问题。

钱包汇总

页面顶部显示钱包余额合计、钱包数量和待定价模型数量。余额合计会使用统一汇率换算，列表中的已忽略钱包不参与合计。

钱包创建与忽略

  • 一个接入地址对应一个钱包，同一地址下的多个 API 密钥归入同一钱包。
  • 新请求首次出现未忽略的接入地址时，扩展会自动创建钱包。
  • DeepSeek 官方钱包始终保留，不能忽略。
  • 删除钱包实际上是加入“已忽略接入”；后续请求不会自动重建，历史记录仍保留原来的钱包归属。
  • 已忽略接入可以在钱包页恢复显示，恢复后再次参与余额统计和新请求归属。

收起与展开

钱包默认收起，收起状态显示钱包名称、接入地址、余额、密钥数量、模型数量、请求数和费用摘要。点击“展开”后显示余额、峰谷、模型价格和价格来源等详细设置。展开状态会按钱包独立记忆。

余额与自动校准

余额方式适用情况说明
手工余额所有钱包直接填写当前可用余额，适合代理、兼容接口或不提供余额查询的接入。
自动校准DeepSeek 官方直连钱包需要钱包内校准密钥和全局自动校准开关；查询成功后覆盖钱包余额。
钱包币种所有钱包用于显示和换算；概览显示会按统一汇率折算。
密钥区别：酒馆中的普通密钥条目只用于识别请求来源；钱包校准密钥是用户主动填写的实际密钥，只用于查询 DeepSeek 官方余额。扩展不会把多个密钥的余额自动相加。

密钥身份与主密钥

  • 扩展可以识别酒馆密钥条目的编号、备注和掩码末三位，用于区分不同请求。
  • 普通反向代理的密码和自定义请求头不会读取、比较或持久化，因此会归入未识别密钥。
  • DeepSeek 官方钱包可以选择一个已识别密钥作为账号身份；未指定时使用钱包内单独保存的校准密钥。
  • 校准密钥不会进入历史、统计、导出或云同步。

峰谷规则

每个钱包可以维护高峰时段，并选择周末是否全天使用低谷价格。峰谷支持跨天规则，例如从晚间开始到次日凌晨结束。

  • 修改峰谷规则后，扩展会重算该钱包可匹配的冷热历史费用。
  • 关闭模型条目的峰谷选项后，该模型始终使用非峰价格。
  • 新钱包会继承设置页配置的默认峰谷时段。

模型与价格

每个钱包维护自己的模型规则。模型条目包含模型名、别名、非峰价格、高峰价格、价格来源、同步状态和锁定状态。

模型名与别名修改模型名时会保留旧名别名，使已经记录的历史仍能匹配价格。
价格来源显示价格是手工、钱包规则、同步规则还是待定价。
锁定锁定的价格在普通同步模式下不会被覆盖；只有明确选择全部覆盖时才可能更新。
待定价没有匹配价格的模型仍会记录 Token 和请求次数，但费用为零，配置价格后自动重算。

计价优先级为：钱包当前规则优先；DeepSeek 官方钱包没有覆盖时使用内置价格；其他钱包没有价格时标记为待定价。

价格来源与同步价格

  • 每个钱包可以选择一个第一方模型厂商作为价格来源，例如 DeepSeek、OpenAI、Anthropic、Google、Mistral、xAI 等。
  • 可选来源只展示第一方厂商，不展示聚合平台或商业化中转渠道。
  • 开启自动同步后，可以从 models.dev 获取模型价格，并按当前钱包的供应商匹配。
  • 同步模式包括仅新增、覆盖未锁定和全部覆盖；关闭同步时会移除未锁定的同步价格并重算历史。

与概览余额口径的关系

概览页选择的余额口径来自钱包列表。选择某个钱包时，余额和基于余额的剩余轮数会使用该钱包；选择全部钱包合计时，会汇总所有未忽略且已设置余额的钱包。统计、历史和趋势中的其他指标仍使用自己的筛选范围。

设置

设置

设置页集中控制全局显示、余额校准、价格机制、价格同步和调试选项。钱包级别的余额与模型价格在钱包页维护。

颜色模式与历史范围

  • 颜色模式提供浅色和深色主题，切换后整个扩展立即生效。
  • 历史显示范围可以选择全部历史或当前对话，主要用于历史记录页的默认范围。

自动校准余额

全局开关决定是否允许钱包按间隔自动查询余额。开启后可以设置校准间隔，单位为分钟。只有钱包页中启用了自动校准且支持官方查询的钱包会执行。

优先级：全局开关关闭时，钱包内即使开启自动校准也不会定时查询；手工余额仍可正常使用。

新价格机制与默认峰谷

  • 开启新价格机制后，可以设置价格生效日期。生效日期前使用旧价格，之后使用峰谷价格。
  • 内置峰谷机制主要面向 DeepSeek 模型，周末可以设置为全天低谷。
  • “新钱包默认峰谷时段”用于新建钱包的默认规则，单个钱包可以覆盖。
  • 修改价格或峰谷规则后，相关钱包的冷热历史会重新计算费用。

模型价格自动同步

开启后，扩展可以从 models.dev 获取模型价格，并把同步结果写入各钱包的价格规则。同步页还提供同步模式、汇率、自动同步间隔、实时汇率和同步后重算历史费用等选项。

选项作用
同步模式决定只补充缺失价格、覆盖未锁定价格，还是覆盖全部可同步价格。
汇率用于把美元价格和其他币种统一换算为显示币种。
自动同步间隔可以选择仅手动或按设定周期自动更新。
同步后重算开启后，价格同步会更新已有历史费用；关闭后主要影响后续请求。
预览在正式同步前查看新增、更新、跳过和待定价数量。

峰值提示圆点

峰值提示圆点用于在扩展入口附近提示当前是否处于高峰时段。可以关闭提示，也可以重置圆点位置。

调试模式

  • 调试模式可以让下一次请求使用模拟 Token 参数，且这些模拟数据不计费。
  • 调试面板可以设置命中、未命中、输出、模型、日期范围和批量条数。
  • 批量生成适合压测图表和表格，但可能重用相同时间戳；它们不会参与真实费用。
  • 使用完模拟数据后，可以在调试面板中清除。
数据管理

导入、导出与 WebDAV

数据管理用于备份历史与钱包配置、恢复旧版数据，以及在多台设备之间保持统计一致。导入和同步都不会包含钱包校准密钥与聊天正文。

导出

导出会包含可用于恢复的历史记录、钱包配置、忽略状态、余额口径和统计设置。导出的历史会清理隐私字段，不包含完整聊天内容或钱包校准密钥。

导入

方式行为适合场景
合并保留现有数据，并导入不重复的记录和配置。从其他设备补齐历史，或恢复部分数据。
覆盖用导入文件替换当前可导入的数据范围。恢复完整备份，或清理当前统计后重新导入。
旧版数据兼容旧版导出格式，并迁移到当前历史结构。从早期脚本或旧版本扩展迁移。
导入前建议：先导出当前数据。覆盖操作不可通过简单的页面撤销恢复。

重复记录处理

历史记录会按时间、模型、Token、接入、钱包和密钥身份进行综合判断。完全重复的记录不会重复累加；同一请求在不同设备上的合并会尽量保留统计一致性。

WebDAV 云同步

  1. 填写 WebDAV 地址、用户名和应用密码。
  2. 按需填写远程子路径；如果服务不允许浏览器直接跨域访问，再填写可用的 CORS 代理地址。
  3. 点击“立即同步”，扩展会执行拉取、合并和推送。
  • 同步内容包括历史、统计设置和钱包配置，不包含聊天正文和校准密钥。
  • 同步使用单向请求完成双向合并，冲突时以记录身份和较新的配置状态处理。
  • WebDAV 地址强制使用 HTTPS，除非由用户自己的代理转发。

同步失败

  • 部分网盘不返回跨域响应头，需要在扩展中填写本地或自建代理。
  • 应用密码和登录密码可能不同，应优先使用服务商提供的应用密码。
  • 远程子路径不存在时，需要先在网盘中创建目录。
  • 同步失败不会清空本地历史；可以继续使用并稍后重试。

检查更新与关于

关于页用于查看扩展信息、仓库地址和更新状态。当前版本以扩展显示为准，本文不固定具体版本号。

检查更新

常见问题

常见问题

以下问题优先从数据来源、筛选条件、钱包价格和浏览器显示环境四个方面检查。

没有记录、请求数不增加或 Token 为零

  • 确认本次请求确实已经完成，而不是只是发送空消息或取消请求。
  • 检查 SillyTavern 的 API 密钥、连接状态和请求地址是否可用。密钥错误或请求中止时，扩展可能没有可记录的用量。
  • 确认当前历史范围选择和设置中的历史范围开关没有过滤掉旧记录；需要时切换为“全部历史”。
  • 如果历史记录出现条目但 Token 为零，应检查上游是否返回了标准用量数据并向开发者反馈。

筛选结果为空

  • 时间、模型、对话、接入和密钥会按交集过滤，任一条件过窄都可能清空结果。
  • 先点击“清除筛选”或恢复“全部”，再逐项增加条件。
  • 切换接入类型后，密钥筛选会自动重置，以避免出现没有交集的旧密钥条件。

模型费用为零

  • 进入钱包页，确认对应模型已经配置价格，且价格来源不是待定价。
  • 确认请求归属的钱包与配置价格的钱包一致。不同接入地址使用各自的钱包规则。
  • 保存价格、修改峰谷或执行价格同步后，检查历史费用是否已经重算。
  • 如果模型名称没有匹配到规则，可以在钱包中增加模型或别名。

钱包没有自动创建

  • 确认请求包含可识别的接入身份，而不是完全未知或已忽略的接入。
  • 检查“已忽略接入”区域；被忽略的地址不会因为新请求自动恢复。
  • 同一接入地址下的多个密钥属于同一钱包，不会按密钥拆分钱包。

图表未显示或显示未就绪

  • 先切换到有数据的统计页面，再等待图表完成初始化。
  • 筛选条件无交集时，图表会显示无数据提示，这是正常状态。
  • 如果页面刚完成更新或窗口大小发生变化，切换一次视图或刷新页面可重新计算尺寸。

WebDAV 无法连接

  • 确认地址以 HTTPS 开头，账号和密码正确。
  • 部分网盘不提供浏览器跨域响应，需要填写可用的 CORS 代理。
  • 确认远程目录存在，并检查应用密码是否具有读写权限。
  • 同步失败不会清空本地数据，可以修复连接后再次同步。

窄屏显示或下拉菜单异常

  • 窄屏下侧边栏会变为抽屉，点击汉堡按钮打开，选择页面后自动收起。
  • 表格、热力图和详情数据使用卡片内部滚动，不应把整个页面撑宽。
  • 如果下拉菜单被相邻卡片遮挡，刷新页面后重试；仍异常时应记录卡片位置和页面宽度。

隐私声明

本声明依据扩展当前实现描述数据访问、本地保存、导出、云同步和外部请求边界。扩展没有遥测、广告或行为分析服务。

扩展会访问哪些数据

数据访问方式用途
请求配置仅在调用酒馆聊天生成接口时读取模型、流式开关、温度、最大输出、顶部概率、接口类型、接入地址和消息数量。记录模型、计价、接入身份和请求参数摘要。

酒馆密钥识别依赖酒馆自身提供的密钥状态。扩展使用密钥条目编号进行匹配，使用用户备注和密钥值的末三位生成可读标签，用于区分请求来源。

  • 完整酒馆密钥不会写入历史、统计、日志、导出文件或 WebDAV 同步包。
  • 识别标签可能包含用户备注和末三位，导出与同步历史时可能一并携带该标签。
  • 如果酒馆版本不提供多条密钥编号，相关请求会归入未识别密钥。

本地历史与详情保留

  • 热历史保存在酒馆扩展设置中，冷历史保存在浏览器 IndexedDB 中。
  • 当前热历史中的最新若干条记录可以保留请求消息、经过清理的请求摘要和响应文本；更早记录的详情会被删除。
  • 单条消息内容存在长度上限，完整响应也存在上限；超长内容会被截断。
  • 原始用量对象 raw_usage 会参与本地统计。它通常由服务商返回，不应假设其中一定没有额外字段。
  • 删除扩展数据、清除浏览器站点数据或删除酒馆扩展设置，可能同时删除本地历史与配置。

钱包校准密钥

钱包校准密钥是用户主动填写的实际密钥，仅用于查询 DeepSeek 官方余额。它保存在独立的扩展设置键中，经 XOR 混淆后落盘，不进入历史、统计、日志、导出文件或 WebDAV 同步包。

安全提示：XOR 只用于避免密钥以直观明文形式出现，不构成安全加密。请使用权限受限、可单独撤销的密钥，并自行评估浏览器与酒馆存储环境的安全风险。

导出与 WebDAV

路径包含不包含
本地导出热冷全量历史、统计数据、钱包配置、余额、显示与计价设置，以及部分连接和计价标识。请求消息、完整请求、完整响应、钱包校准密钥；导出时 WebDAV 地址和账号字段会被清空。
WebDAV 同步当前构造同步包时的扩展历史、统计快照、钱包配置、忽略状态和设置。请求消息、完整请求、完整响应、钱包校准密钥和 WebDAV 密码。
导入兼容格式中的历史统计、钱包配置和设置。导入时跳过请求消息、完整请求、完整响应和原始用量字段。

导出文件仍可能包含接入地址、密钥标签、钱包名称、模型价格和原始用量对象，应按敏感文件保管。调试模式生成的模拟记录不会进入导出或 WebDAV 同步包。

WebDAV 密码

WebDAV 密码经 XOR 混淆后保存在浏览器本地存储和扩展设置中，仅用于构造访问用户指定 WebDAV 地址所需的认证请求。该密码不会进入导出文件或 WebDAV 同步数据包。

代理风险：如果用户配置非 HTTPS 的 CORS 代理，WebDAV 用户名和密码可能在传输过程中被第三方读取。扩展会提示并需要用户确认后才继续。
